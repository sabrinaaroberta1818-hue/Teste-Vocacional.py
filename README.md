# Teste-Vocacional.py
Repositório criado para apresentar habilidades de programação em Python por meio de um projeto com alto potencial de escalabilidade, que pode e deve crescer à medida que avanço nos meus estudos.

O "Voz Do Amanhã" é um teste vocacional desenvolvido em Python que busca ajudar os usuários a refletirem sobre seus interesses, habilidades e preferências profissionais. A aplicação funciona no terminal, apresenta 50 perguntas de múltipla escolha e calcula a pontuação dos perfis com base nas respostas.
Este projeto tem finalidade de autoconhecimento educacional. Os resultados não representam uma avaliação psicológica ou orientação profissional definitiva.

PLANO DE ESCALABILIDADE:

VERSÃO 1 (versão atual): Console; Python; PostgreSQL; 5 scales.

VERSÃO 2: Refatoração.

VERSÃO 3: Integração SQL.

VERSION 4: Interface Gráfica.
